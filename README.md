# Student Information Card

A simple Java program that displays a formatted student information card. The program shows basic student details including name, major, graduation year, email address, hometown, and favorite hobby.


## Features

- Display student name (original)
- Display major and graduation year (original)
- Display email address (added)
- Display hometown (added)
- Display favorite hobby (added)
- Display formatted section headers (added)
- Include code comments explaining the program (added)

## Technologies Used

- Java
- Git for version control
- GitHub for repository hosting

## Installation and Setup

### Prerequisites
To run this program, you need:

- A computer
- Java Development Kit, also called JDK
- Git
- A code editor or terminal, such as Visual Studio Code

### Steps to Run

1. Clone this repository:
   ```
   git clone [url for the command you used]
   ```

2. Navigate to the project directory:
   ```
   cd [your project name]
   ```

3. Run the program:
   ```
   python student_info.py
   ```
   OR (for Java):
   ```
   javac StudentInfo.java
   java StudentInfo
   ```

## Development Process

For this project, I practiced using a professional Git workflow by working on a feature branch instead of making changes directly on the main branch. I made separate commits for each logical change, including adding an email address, hometown, favorite hobby, formatting improvements (such as adding a header), and code comments. This helped me understand why small commits are useful because they make the project history easier to follow. Although, again, my email address in the CougarView instructions was amusing and unexpected.
